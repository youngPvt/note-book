# 产物模块

本模块管理运行输入、输出和验证证据的持久化、版本、访问与保留。产物以稳定 ID 和内容摘要被执行结果、事件及记忆引用，执行层据此判断必要材料是否已经可靠保存。

## 元数据、持久化与访问

产物包括上传输入、检索导出、执行报告、代码补丁、测试结果和生成文档。关系库保存元数据，对象存储保存内容，事件和记忆通过 ID 引用。

`Artifact` 至少保存 `artifact_id`、租户及工作区、Run 和 Attempt、类型、大小、内容摘要、对象版本、来源、可见策略与保留期限。代码相关产物额外记录仓库、基线 Commit 和结果 Commit。

上传采用 `UPLOADING → READY` 状态，服务端校验对象存在、大小及摘要后提交可见元数据。Agent 结果只引用 READY 产物。内容更新生成新版本，已有版本保持稳定。重复提交通过操作 ID 和内容摘要识别。

申请下载时重新验证当前权限，使用短期签名地址或受控下载接口。已签发地址通常在到期前仍有效，采用签名地址时明确有效期和撤销延迟。要求撤权后阻止后续下载请求的产物，统一经过受控接口逐次鉴权。

对象路径中的租户前缀只用于组织资源，实际权限由访问服务和存储策略共同控制。删除先撤销平台访问资格，再异步清理内容和衍生引用，按交付方式处理已签发地址，清理任务可查询并重试。

最终结果、独立验证报告与过程文件分别标记用途。例如模型输出的“测试通过”保存为执行描述，测试命令退出状态、测试报告和 CI 记录分别保存证据，业务流水线据此判断是否满足验收条件。

## 渐进式加载边界

平台先保存产物内容和元数据，模型默认获得任务相关的清单、类型、摘要与引用。需要检查、修改或验证时，再按授权读取具体文件、页段或内容片段，较大结果保持摘要与引用。

文件下载或挂载到工作区只表示执行环境可以访问，不能据此认为全文已经进入模型上下文。在执行器开放的可见范围内记录读取范围、来源版本和内容裁剪，未暴露的内部读取细节标记为未知，具体规则见 [上下文模块](../03-context/README.md)。
