# 评测模块

本模块验证回答、动作和交付结果的质量，支持 Agent 版本发布前回归及上线后的授权复核。评测使用可追溯样本和独立证据，并与运行稳定性统计、上层业务验收保持明确关联。

## 质量验证与发布

评测覆盖三类问题。回答类检查来源与正确性，动作类检查参数、权限和工具结果，交付类检查独立测试及验收条件。评测记录绑定 AgentVersion、模型、Skill、Runtime 和样本集版本，发布前做回归，线上按授权采样复核。Run 执行成功与业务验收通过分别统计。

验收通过率、人工修改量、代表性问题正确率和每次有效交付成本由已确认的业务或评测记录计算，再交由可观测性模块展示。模型自述、工具返回、独立测试和业务验收应分别保留来源，避免仅根据 Run 成功状态推导交付质量。
