# Skill 模块

本模块管理可复用操作方法的注册、验证、发布和运行装载。一个 Skill 可以承载整个任务的方法、步骤、判断条件，以及需要的资源和脚本。平台维护不可变版本及授权范围，Agent Runtime 使用这些内容驱动任务执行。

当前架构由 Agent Runtime、Skill 和工具配合：Skill 说明任务怎么做，Runtime 推进 Agent 循环、保存状态、处理恢复和预算停止，工具服务检查实际操作权限及关键业务前置条件。具体执行边界见 [Agent 循环与 Runtime 适配](../03-execution/README.md#agent-循环与-runtime-适配)。

## 注册发布与运行装载

Skill 描述一项可复用的方法，可以包含操作说明、参考资料、脚本和模板。目录结构可采用 Agent Skills 规范，以 `SKILL.md` 保存元数据与正文，按任务需要加载详细内容和附属文件。[Agent Skills 规范](https://agentskills.io/specification)

| 管理环节 | 需要保存或检查的内容 |
| --- | --- |
| 注册 | 名称、用途、负责人、来源、适用 Runtime 与环境依赖 |
| 版本 | 不可变包、内容摘要、依赖版本、变更记录 |
| 验证 | 格式与引用检查、脚本检查、代表性任务评测 |
| 发布 | 发布状态、授权范围、允许引用的 AgentVersion |
| 装载 | 需要发现方法时提供可见元数据；已选定 Skill 可直接加载固定版本正文，再按需读取资源 |
| 停用与回滚 | 更新允许使用的版本，处理受影响的新旧运行 |

平台在规范之外维护包版本、依赖清单和评测记录。Skill 中声明需要某个工具时，发布和执行阶段都核对权限。脚本在对应沙箱内运行，其资源和网络权限受执行身份约束。

不同 Runtime 的 Skill 原生支持程度可能不同。适配层声明目录挂载、按需加载和脚本调用能力。需要自行装载时保存实际注入的内容版本，评测其行为是否满足要求。

程序性记忆可以指向 Skill 或 Prompt 的发布版本。Skill/Prompt 仓库保存正文，记忆服务保存适用条件、来源和评测关联。任务提炼出的改进先形成候选，经评测与发布后供新版本使用。

SkillVersion 的内容模型分为召回信息 `recall`、正文 `instructions`、附属资源 `resources` 和能力依赖 `dependencies`。`references` 是可选的参考资料目录，脚本、模板也属于资源；独立 Skill 和工具则通过依赖引用。字段、包结构和发布校验见 [Skill 数据模型与资源依赖](./02-Skill数据模型与资源依赖.md)。

## 渐进式加载边界

平台先准备允许使用的 Skill 版本和依赖。任务入口已明确所用 Skill，或用户已经选定 Skill 时，可以直接加载绑定版本正文；需要发现方法时，少量 Skill 提供名称与用途，目录较大则通过 `search_skills` 检索候选，再通过 `load_skill` 加载选中正文。执行到具体步骤时再读取参考资料、模板或脚本。脚本可在沙箱中直接执行，其源码不必全部进入模型上下文。

全局、租户自有及平台授权的 Skill 使用统一目录管理，检索范围再受当前 Agent 配置限制。完整的数据模型、索引与运行链路见 [多租户 Skill 配置存储与运行时加载](./01-多租户Skill配置存储与运行时加载.md)。

挂载 Skill 目录只表示资源可访问，实际正文和附属文件何时进入上下文，由 Runtime 原生能力或适配层按任务决定。装载时仍核对版本、权限和预算，具体规则见 [上下文模块](../04-context/README.md)。

Worker 可以按不可变版本缓存正文和包文件，缓存命中减少远端读取，模型输入量仍由实际注入内容决定。搜索加载的额外轮次、正文长度和文件读取耗时需要分别观测，具体见 [Skill 渐进式加载与缓存](./03-渐进式加载与缓存.md)。
