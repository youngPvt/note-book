# Skill 全流程知识点拆解

Skill 可以承载整个任务的方法、步骤和所需资源。需要发现方法时，执行链路包含使用判定、候选召回、最终选择、内容加载、动作执行和结果验证；任务入口或用户已选定 Skill 时，可以直接加载其绑定版本。组合、状态恢复、权限、版本与评测围绕这条链路提供支撑。

本页按能力拆成八组、34 个细知识点，用于理解每一步解决什么问题、由哪个模块保证。具体故障现象与处理方式见 [Skill 典型问题总纲](../../case/08-skills/00-Skill典型问题总纲.md)；已有项目案例继续保留各自来源和验证范围。

## 知识点目录

1. [Skill 选择](#01-skill-选择)：是否需要、能否召回、是否选对。
2. [Skill 内容加载](#02-skill-内容加载)：版本获取、正文传输、资源展开与异常处理。
3. [Skill 执行控制](#03-skill-执行控制)：前置条件、决策边界、动作正确性与完成判定。
4. [多个 Skill 的组合](#04-多个-skill-的组合)：组合必要性、依赖、执行顺序、交接与冲突。
5. [Skill 状态与恢复](#05-skill-状态与恢复)：缓存、激活、上下文、业务进度与恢复一致性。
6. [Skill 权限与隔离](#06-skill-权限与隔离)：可用范围、实际操作、作用域与权限变化。
7. [Skill 发布与版本管理](#07-skill-发布与版本管理)：完整性、兼容性、一致性与升级回滚。
8. [Skill 效率与效果评测](#08-skill-效率与效果评测)：动作效率、耗时成本、稳定性、实际增益与变更验证。

## 01 Skill 选择

选择阶段分别回答“要不要用、候选中有没有、最后选了谁”。正确候选已经返回但模型选错，属于选择问题；候选里根本没有适用能力，先检查召回与范围过滤。

| 编号 | 细知识点 | 要回答的问题与关键边界 |
| --- | --- | --- |
| 1.1 | 使用判定 | 当前任务需要专门方法，还是已有模型与工具即可完成？允许无需 Skill、无合适方法和需要澄清三种情况，不强制每次激活。 |
| 1.2 | 候选召回 | 适用 Skill 是否进入候选？分别检查语言与别名、描述解析、检索策略、当前权限、绑定版本和目录预算。 |
| 1.3 | 最终选择 | 模型是否选择并请求激活适用的 Skill？多个候选需要取舍，无匹配时可以有限补搜或放弃；选中不代表内容加载或后续执行已经成功。 |

使用判定与候选召回可以在实现中协同进行，不要求为每一步新增一次模型调用。已选定的方法可以直接加载，仍核对当前权限与绑定版本。评估时分别准备直接加载、需要发现 Skill、无需 Skill、无适用候选和相似能力混淆的样本。

设计：[大量 Skill 的检索与召回](./01-多租户Skill配置存储与运行时加载.md#大量skill的检索与召回)。案例：[中文召回与描述解析](../../case/08-skills/01-召回与元数据.md)。问题集合：[召回不准确](../../case/08-skills/00-Skill典型问题总纲.md#01-skill-召回不准确)。

## 02 Skill 内容加载

加载阶段将选中的方法转成执行时可用的内容。要分别确认文件已取得、工具结果已返回、内容已进入下一次模型输入。

| 编号 | 细知识点 | 要回答的问题与关键边界 |
| --- | --- | --- |
| 2.1 | 版本获取 | 能否取得选中且允许使用的版本？正文、资源地址与摘要应对应绑定版本，读取失败不能静默切换 latest。 |
| 2.2 | 正文传输 | 正文是否实际进入模型输入？检查 SDK 截断、输入预算和上下文组装，接口返回成功不代表全文已生效。 |
| 2.3 | 资源展开 | 模型是否知道何时读取 references、运行 scripts、使用模板？正文说明使用条件，Runtime 提供读取或执行入口，文件可访问不等于已经被模型读取。 |
| 2.4 | 加载异常 | 缺文件、超预算或临时读取失败时如何处理？区分当前必需与暂不使用的内容，选择补读、有限重试、继续或停止受影响步骤。 |

资源按类型使用：参考文字按需进入上下文，脚本交给执行工具，模板交给生成工具。资源目录存在不会自动触发这些动作。

设计：[从召回到资源使用](./03-渐进式加载与缓存.md#从召回到资源使用)。案例：[正文被工具结果截断](../../case/04-context/01-Skill正文被工具结果截断.md)、[资源缺失与按需读取](../../case/08-skills/02-资源缺失与按需读取.md)。

## 03 Skill 执行控制

正文可以说明整个任务的方法、步骤和条件。Agent 据此决定动作，Runtime 驱动循环并管理状态恢复、预算与停止。必须满足的权限和业务前置条件由工具服务检查，独立验证程序提供可核对的结果。

| 编号 | 细知识点 | 要回答的问题与关键边界 |
| --- | --- | --- |
| 3.1 | 前置条件 | 输入、业务数据、工具和环境是否满足执行要求？必要信息缺失时先补充或返回明确失败，不能把缺失默认成已满足。 |
| 3.2 | 决策边界 | 哪些步骤允许模型自由判断，哪些必须按顺序或规则执行？任务方法与顺序可以写进 Skill，关键业务前置条件应由工具服务或验证程序检查。 |
| 3.3 | 动作正确性 | 是否真正调用了正确工具，参数、对象、单位、时间范围及顺序是否正确？参数格式正确还需通过业务语义和访问检查。 |
| 3.4 | 完成判定 | 满足什么条件才能宣布完成？以产物检查、外部状态和必要验收为准，模型完成文案与工具返回成功只能作为过程信息。 |

例如“生成报告后校验，再允许发布”：Skill 指导 Agent 生成并校验报告；发布工具检查校验记录是否对应当前产物、当前状态是否允许发布，以及调用者是否有权限。未满足条件时拒绝操作，并把原因交回 Agent 处理。

设计：[Agent 循环与 Runtime 适配](../03-execution/README.md#agent-循环与-runtime-适配)。案例：[Excel 生成内容丢失](../../case/11-artifacts/01-Excel生成内容丢失.md)。问题集合：[选对但执行不正确](../../case/08-skills/00-Skill典型问题总纲.md#02-召回准确但执行不正确)。

## 04 多个 Skill 的组合

发布时的依赖关系描述需要哪些能力及版本，不会自动转换为执行 DAG。Skill 正文说明组合方法、使用条件、输入输出和失败处理，Agent 根据当前状态与工具反馈推进。同一个 Agent 可以组合多个 Skill，加载另一个方法本身不会自动创建子 Agent 或子 Run。

| 编号 | 细知识点 | 要回答的问题与关键边界 |
| --- | --- | --- |
| 4.1 | 组合必要性 | 多个 Skill 是否各自承担不同职责？一个方法足够时，额外组合可能只增加选择和上下文成本。 |
| 4.2 | 依赖解析 | 被引用的 Skill、工具和固定版本是否存在、兼容且允许使用？依赖声明不自动授予权限。 |
| 4.3 | 组合执行 | 哪些步骤顺序、条件执行或可并行？Skill 说明方法，Agent 在 Runtime 内推进；工具服务检查必须满足的前置条件，不能仅凭依赖列表推断执行顺序。 |
| 4.4 | 结果交接 | 上一步输出如何成为下一步输入？明确字段、产物引用、状态与校验条件，避免交接一个含糊的“已完成”。 |
| 4.5 | 冲突处理 | 指令、版本、参数或修改目标冲突时怎么办？固定兼容版本，限定阶段和工作范围，对共享修改建立顺序或合并规则。 |

例如报告 Skill 依赖图表 Skill，还需约定图表接收哪些数据、返回哪个文件、失败后能否继续，以及多个步骤是否会修改同一个报告。

设计：[dependencies 能力依赖](./02-Skill数据模型与资源依赖.md#dependencies-能力依赖)、[发布与依赖校验](./02-Skill数据模型与资源依赖.md#发布与依赖校验)。问题集合：[步骤过多](../../case/08-skills/00-Skill典型问题总纲.md#03-执行正确但步骤太多)、[版本与兼容性](../../case/08-skills/00-Skill典型问题总纲.md#07-发布版本与兼容性)。

## 05 Skill 状态与恢复

至少需要分别理解以下五个状态或一致性问题。一个 `loaded=true` 不能同时表达文件存在、权限有效、正文驻留和业务已经完成。

| 编号 | 细知识点 | 要回答的问题与关键边界 |
| --- | --- | --- |
| 5.1 | 内容缓存状态 | 某个固定版本的文件是否已缓存？缓存只影响内容获取，不代表已激活、已注入或仍有权访问。 |
| 5.2 | 激活状态 | 当前哪些 Skill 仍处于有效激活状态？激活集合受租户与 Agent 允许范围限制，不能累积全部历史加载记录作为永久许可。 |
| 5.3 | 上下文状态 | 正文和关键资料是否仍在当前模型输入中？压缩或移除后按需要重新加载，正文被移除本身不等于授权发生变化。 |
| 5.4 | 业务执行状态 | 哪些步骤已经完成，哪些外部动作结果确定或仍待核对？记录业务结果，不能用模型记忆或激活记录代替。 |
| 5.5 | 恢复一致性 | checkpoint、上下文、工作文件、版本和外部动作能否对齐？恢复时补充所需内容，并防止重复执行已完成的副作用。 |

例如创建工单已成功，但 Skill 正文后来被压缩。恢复时可以重新加载方法，同时保留原操作结果；重新加载正文不意味着重新创建工单。

设计：[内容缓存与上下文驻留](./03-渐进式加载与缓存.md#内容缓存与上下文驻留)、[外部副作用与恢复](../03-execution/README.md#外部副作用与恢复)。案例：[激活集合与权限守卫不一致](../../case/03-execution/01-Skill激活集合与工具授权.md)。

## 06 Skill 权限与隔离

配置允许范围、当前激活集合和实际动作权限分别回答不同问题。身份与策略由服务端提供，模型只能在受支持的接口内提出读取和执行请求。

| 编号 | 细知识点 | 要回答的问题与关键边界 |
| --- | --- | --- |
| 6.1 | 发现与加载范围 | 当前租户和 Agent 可以搜索、看到和加载哪些 Skill？全局、自有及获授权资源先合并，再受 Agent 配置收窄。 |
| 6.2 | 实际操作权限 | 当前工具、目标文件和业务数据是否允许访问？Skill 可加载不等于拥有其中提及的一切操作权限。 |
| 6.3 | 作用域生命周期 | 读取限制与激活状态属于哪个请求、Run 或会话？定义创建、传递、更新和清理边界，避免跨任务残留与并发串用。 |
| 6.4 | 权限变化 | 撤权、停用或任务切换后，哪些状态需要更新？资源与工具访问检查当前有效状态，缓存命中不能绕过限制。 |

设计：[租户配置服务与执行权限](../01-management/02-租户配置服务与执行权限.md)。案例：[工具可见但被拒绝及请求范围残留](../../case/03-execution/01-Skill激活集合与工具授权.md)。问题集合：[权限隔离与不可信内容](../../case/08-skills/00-Skill典型问题总纲.md#06-权限隔离与不可信内容)。

## 07 Skill 发布与版本管理

发布准备、版本一致性与当前停用状态共同决定内容能否使用。SkillVersion 固定内容，AgentVersion 固定选择的依赖，当前策略决定是否仍允许访问。

| 编号 | 细知识点 | 要回答的问题与关键边界 |
| --- | --- | --- |
| 7.1 | 发布完整性 | 正文、资源清单、元数据和检索索引是否准备完成？明确可发布条件与准备失败状态，避免上传成功就立即对外宣称可用。 |
| 7.2 | 兼容性校验 | 模型、Runtime、工具与执行环境能否支持该方法？格式合规、客户端能加载、任务执行成功分别验证。 |
| 7.3 | 版本一致性 | 召回描述、正文、资源、依赖和缓存是否对应确定的版本组合？使用固定版本和摘要，更新生成新版本。 |
| 7.4 | 升级与回滚 | 新发布影响哪些任务，在途运行如何处理？普通升级通过新配置生效；问题版本的停用和撤权需要作用于后续实际访问。 |

设计：[上传发布与版本绑定](./01-多租户Skill配置存储与运行时加载.md#上传发布与版本绑定)。问题集合：[发布版本与兼容性](../../case/08-skills/00-Skill典型问题总纲.md#07-发布版本与兼容性)。

## 08 Skill 效率与效果评测

动作是否多余、时间花在哪里以及结果是否稳定需要分别评估。优化以相同业务验收条件为前提，不将必要的授权、补读或验证简单算成无效步骤。

| 编号 | 细知识点 | 要回答的问题与关键边界 |
| --- | --- | --- |
| 8.1 | 动作效率 | 哪些搜索、重载、读取、工具调用与反思是必要的？结合轨迹与任务状态定义冗余，观察是否因接口或状态错误反复绕行。 |
| 8.2 | 时间与费用 | 耗时来自网络、模型输入处理、生成还是业务工具？区分冷暖缓存、额外模型轮次与实际执行成本，不预设单一瓶颈。 |
| 8.3 | 结果稳定性 | 同类任务重复执行是否持续通过验收？使用正反例、边界与失败样本，固定条件进行多次评估。 |
| 8.4 | 实际增益 | 不用 Skill、直接提供正确 Skill、搜索后加载分别表现如何？区分方法收益和发现加载损失，观察成功率、成本与人工修正负担。 |
| 8.5 | 变更验证 | 改了描述、正文、脚本、模型或 SDK 后如何验证？保留独立回归样本，比较逐项结果与费用时延，区分实测、估算和未知信息。 |

设计：[长文本与运行时延](./03-渐进式加载与缓存.md#长文本与运行时延)、[Agent 自动化评测](../13-evaluation/01-Agent自动化评测与效果量化.md)。问题集合：[效果评测与故障定位](../../case/08-skills/00-Skill典型问题总纲.md#08-效果评测与故障定位)、[三组对照与指标](../../case/08-skills/00-Skill典型问题总纲.md#如何证明-skill-真正有帮助)。
