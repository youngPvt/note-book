# 模型接入与调用治理

模型模块管理模型能力契约与实际调用适配，衔接管理层的配置和执行层的模型请求。管理层负责目录、发布与授权，模型运行组件落实调用策略，并把实际结果和用量交还执行层。

## 模型配置与运行治理

管理层维护 Provider、ModelProfile、凭证引用、能力标签和用量策略。能力标签至少覆盖文本或多模态输入、工具调用、结构化输出、上下文上限，以及兼容的 Runtime。参数范围以所用模型和后端的实际支持情况为准。

执行路径使用模型调用适配器落实超时、限流、重试和用量记录。支持自定义模型客户端的 LangGraph 节点可以统一经过模型网关。SDK 自带的模型调用链路按其开放接口配置，平台在调度、预算和网络出口层补齐可实施的约束。

备用模型只在已验证的兼容组合内启用，记录实际使用的模型与降级原因。切换可能改变工具调用或输出行为，因此需在发布前评测。SDK 会话能否换模型、续用历史和经过统一网关，都必须在 Runtime 能力表中声明。

模型配置保存价格版本或计费规则，用量账本保存供应商返回值与估算值的区别。费用、token、工具调用次数和总时限均可设上限。内部用量不可完整观测的执行器，按可见数据统计，并用进程时限、任务并发及供应商侧额度补充控制。

## 与其他模块协作

模型访问组件承接执行器支持的调用路径，落实管理层配置的模型参数、限流、超时、预算和用量采集。SDK 内部调用链路的配置与观测范围以适配器声明为准，具体边界见 [管理层设计](../01-management/README.md)。

[上下文模块](../04-context/README.md)决定本轮采用的材料和工具定义，模型适配器将其转换为后端接受的请求格式。[执行层](../03-execution/README.md)管理调用所处阶段、停止条件和恢复，[可观测性模块](../12-observability/README.md)接收可见的调用事件与用量，[评测模块](../13-evaluation/README.md)验证模型或参数变化对任务效果的影响。

## 后续细化专题

- Provider 与 ModelProfile 的数据模型、能力校验和配置版本。
- 模型客户端接口、流式输出、工具定义与结构化结果适配。
- 限流、超时、重试、预算和用量账本的实现。
- 备用模型选择、兼容性评测与切换记录。
- SDK 内部调用的配置范围、可见用量和供应商额度控制。
