# 知识检索模块

本模块提供有来源、带版本且经过授权的文档证据，负责知识源接入、索引生命周期与检索。执行层取得检索结果后决定如何使用，长期事实和经验的积累由记忆服务管理。

## 知识接入与检索

既有 RAG 服务可以作为公共检索能力接入，负责知识源同步、解析切分、版本和 ACL 同步、索引更新、召回及重排。执行层按问题调用，取得文档 ID、版本、片段位置、引用地址和授权后的内容，再决定如何进入上下文。

检索从可信执行身份计算可访问范围，将 ACL 下推到召回查询，再执行重排。索引无法表达过滤条件时，使用授权 ID 集合或已隔离分区约束候选。返回结果与缓存命中时再次检查权限和内容有效性。

知识源停用、文档删除和权限变更需要同步到索引与缓存。索引构建失败记录可重试进度，查询结果带已索引版本，便于识别数据新鲜度。检索评测使用代表性问题和可核验来源。

知识检索负责提供文档证据，记忆服务负责管理跨任务积累的事实和经验。两者共享鉴权与来源约定，通过文档版本关联失效处理。

## 渐进式加载边界

平台先完成文档同步、解析、索引及 ACL 准备。模型提出问题或流程进入检索节点时，才召回相关片段及引用，按证据需要继续扩大检索或读取原文。知识库已索引不代表全文进入模型上下文。

每次召回与补充读取都重新检查当前权限，返回内容由上下文组装器按相关性、来源和 token 预算选取。具体规则见 [上下文模块](../context/README.md)。
