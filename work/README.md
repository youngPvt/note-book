# 企业 Agent 项目面试复习

这组笔记围绕企业知识助手和微型研发需求交付，按面试时的讲述顺序整理。先讲最终能做什么，再用一条任务解释架构，最后回答技术取舍和演进过程。

1. [项目主线与口述稿](./01-企业Agent项目主线.md) — 熟读项目定位、两类入口、整体架构和需求执行链路。
2. [核心技术与故障处理](./02-核心技术与故障处理.md) — 理解权限、RAG、任务状态、沙箱、恢复、断线重连及验收。
3. [选型追问与时间线](./03-选型追问与时间线.md) — 练习选型回答，核对产品时间点，补齐个人贡献与项目证据。
4. [基座知识清单](./base/README.md) — 整体架构与 13 个模块，各模块下组织细知识点。
5. [面试复习计划](./review-plan/README.md) — 一周复习安排、深度自测、项目口述与案例整理。
6. [典型问题与解决方案](./case/README.md) — 与 base 使用相同模块目录，整理实际故障、修复方式、验证范围与代码证据。

每轮复习先脱稿讲两分钟项目，再讲一遍“订单列表增加创建人筛选”的执行过程，最后选三个故障场景回答。能够解释处理顺序、状态变化和结果验证，就掌握了这段讨论的主要内容。

原会话明确说过要为面试构思项目故事，其中 RAG 起步、五人团队和后续实施阶段包含假设。本文保留这些设计作为复习材料，第一人称口述稿属于待核实模板。正式用于项目经历前，请填实第三篇末尾的个人职责、实施状态和证据记录。
